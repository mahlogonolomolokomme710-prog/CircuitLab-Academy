# v0.5 validation checklist

- [ ] Run `python install_circuitjs.py` successfully.
- [ ] Confirm both required local asset files exist.
- [ ] Start `streamlit run app.py` and check the home page.
- [ ] Open Prepared Circuit Library and confirm the green self-hosted-assets message appears.
- [ ] Open all five prepared examples; confirm the circuit loads and responds to edits.
- [ ] Check the hosted fallback is not being used.
- [ ] Check notes download works.
- [ ] Only then commit/push to GitHub and verify the deployed app after Streamlit redeploys.
